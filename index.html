莫尔圆的构建原理

一句话

一点的应力状态是一个二阶张量。当截面方向连续改变时，截面上的正应力 σ 与剪应力 τ 的变化轨迹必然是一个圆——这就是莫尔圆。

一、斜截面上的应力

取三角形微元，斜截面法线与 x 轴成角 α。由力平衡得：

σα = (σx+σy)/2 + (σx−σy)/2·cos2α + τxy·sin2α
τα = −(σx−σy)/2·sin2α + τxy·cos2α

注意右边全是 cos2α、sin2α：角度一进来就翻倍，这是莫尔圆最核心的特征。

二、消去参数，得到圆

把两式中的 2α 消掉并配方：

(σα − C)² + τα² = R²
C = (σx+σy)/2, R = √[ ((σx−σy)/2)² + τxy² ]

这就是一个圆心在 (C, 0)、半径为 R 的圆。σ、τ 是「坐标」，α 只是「参数」——所以 α 取遍 0~180° 时，点 (σ, τ) 恰好绕圆一周。

三、为什么两个点就能定出这个圆

x 面与 y 面在实物上夹角是 90°，但在圆上对应 180°——因为它们互为直径的两端。背后的原因正是那个「二倍角」：应力是二阶张量，截面转 180° 应力状态完全复原。

所以作图时：取 A(σx, τxy) 代表 x 面，B(σy, −τxy) 代表 y 面，AB 就是一条直径，圆心是它的中点，半径是它的一半。圆由此唯一确定。

四、圆上能读出什么

σ₁,₂ = C ± R
τmax = R, 对应截面与主平面成 45°

圆与 σ 轴的两个交点就是主应力（τ = 0 的面）；圆的最高点、最低点就是最大剪应力。任意截面从 A 点起沿圆转 2α 即可找到。

五、三维应力状态：三个圆

三向应力下，主应力 σ₁ ≥ σ₂ ≥ σ₃ 两两组合出三个圆。任意截面上的 (σ, τ) 一定落在大圆之内、两个小圆之外的那块区域——也就是图里浅蓝色填充的部分。

σn = σ₁n₁² + σ₂n₂² + σ₃n₃²
τn² = σ₁²n₁² + σ₂²n₂² + σ₃²n₃² − σn²

n₁、n₂、n₃ 是截面法向的方向余弦。当某个 nᵢ = 0，点就落到对应的那个圆上；三点同时非零，点落在区域内部。

六、莫尔—库仑强度理论

把不同围压下的破坏状态画成圆，它们的公切线就是强度包线：

τf = c + σ·tanφ

应力圆与包线相切即表示破坏。相切时破坏面与最大压应力方向成 45° + φ/2。

注意本图 σ 轴以拉为正（材料力学约定），而土力学多以压为正，所以包线的斜率在这里显示为负——把它理解成「同一条线，坐标轴方向相反」即可。

七、一般应力分量怎么进来

输入 σx、σy、σz、τxy、τyz、τzx 后，程序对 3×3 对称应力矩阵做特征值分解：

[σ]·v = λ·v → λ = σ₁, σ₂, σ₃

特征值就是三个主应力，特征向量就是三个主方向。单元体上那组倾斜的箭头画的就是主方向——它们相对材料坐标是斜的，这正是「主应力方向」的含义。

八、常见误区

· 圆上的角度是实际角度的两倍：圆上转 60°，截面只转了 30°。

· 剪应力的正负号约定必须全程统一，否则圆会画反。

· 二维莫尔圆只是三维的特例（σ₂ = 0 或平面应力），别把两个小圆当成「错误」。
